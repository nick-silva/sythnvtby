    Clear paint

      Colour is stored per tile pattern, so a tile shared with another pose can only lose its colour everywhere. Undo brings it back; it is written to the pack only when you save.

      Find poses

      New poses

      Poses the frames show that this character has not kept. Each is kept from the first frame showing it.

      Kept twice

      Poses with the same tiles in the same places (for a sprite, also one that is the other's mirror image). Removing one moves its animation steps, and its overpaint if the one kept has none, to the one kept; the tiles and their paint stay.

      Find sprites

      Small bits

      Sprites of one or two tiles that share nothing with another: sparks, digits, bits of debris. Not ticked; tick any that is a character of its own.

      Auto-paint

      Colours the poses ticked Paint from the poses ticked Learn from. Only pixels nobody chose a colour for are painted, and one Undo takes it all back. A pose learns best from poses facing the same way: a side view from a side view.
